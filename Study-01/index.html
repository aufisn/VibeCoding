Study-01 · Handwriting Recognizer

You draw a single character (0-9, A-Z, a-z) and a scikit-learn model predicts it. The page sends each drawing to a Python server that runs the model, and GitHub Pages can't run Python. So this one has to run on your own computer.

Clone the repository, then from the Study-01 folder:

python3 -m venv .venv
.venv/bin/pip install scikit-learn numpy pillow joblib
.venv/bin/python web_version/server.py   # then open http://localhost:8000
